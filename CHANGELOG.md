# Changelog

What each package update changed. Newest first within each package. The
updates arrive through Configure → Updates (or `apt full-upgrade`); the
next images include them.

## Coming next (built, not yet packaged)

In the packaging now (`packages/riscos-rom/preinst`); 5.31-30 itself is unchanged and isn't reissued for it.

| 5.31-29 | 13 Nov 2026 | **The desktop no longer stops dead (nothing but Ctrl-Break works) some minutes after a program that uses timers has been busy or was stopped:** removing a timer (OS_RemoveTickerEvent) was meant to happen with interrupts off, and in this port they stayed on, so a clock tick arriving at just the wrong instruction could tie RISC OS's list of timers into a loop. A ROM build on a RAM disc failed within seconds (Chris Gransden's report); so did setting a file's pointer past its end on a small RAM disc (the web browser project's report). | 5.31-24 | 11 Nov 2026 | **Memory behaves as it does on a real RISC OS machine at the edges of dynamic areas:** a new dynamic area goes at the lowest free address, working upwards, as RISC OS does everywhere else, so what lies just past it is normally free and running off its end stops with a data abort, as on a Pi running RISC OS. Before, Linux chose the addresses, top down, each new area directly under the last, so an overrun quietly read or wrote the area made before it: programs with such a fault ran here and stopped on real machines (found comparing native RISC OS with RISC OS on Linux on the same Pi; the web browser project's report). Areas also no longer sit at addresses with the top bit set. **The RAM disc can be up to 2 GB** (it was 128 MB), as on native RISC OS 5.3x (Chris Gransden's report). **A pointer turned off goes off:** a program that hides the pointer (!RDPClient over its window) no longer leaves the last pointer frozen on the screen (Chris Gransden's report). **Room for SWIs without a trap** (with riscos-support 1.0.0041-1): the ROM's busiest SWI calls can go straight to the SWI handler. Built with the DDE 32d; 5.31-20 to 5.31-23 were test builds and weren't packaged. |
| 5.31-19 | 8 Nov 2026 | **Configure's mouse speed works** (with riscos-support 1.0.0034-1 or later): a mouse's movement now reaches RISC OS as movement, so RISC OS applies its mouse speed to it, as on a Pi.
